# ذهب لايف — GoldLive

تطبيق أندرويد يعرض أسعار الذهب لحظياً بالدولار والريال السعودي والليرة السورية.

## المزايا
- **سعر الأونصة** بالدولار والريال والليرة، يتحدث تلقائياً (كل 5 / 10 / 30 / 60 ثانية حسب الإعدادات)، مع مؤشر "مباشر" ووميض أخضر/أحمر عند تغير السعر
- **سعر الغرام** لعيارات 24 / 22 / 21 / 18 (و14 اختيارياً) بالعملات الثلاث
- **نسبة التغير اليومي** ومعرفة إغلاق السوق في عطلة نهاية الأسبوع
- **مخطط بياني** يومي / أسبوعي / شهري / 3 أشهر، بأي عملة، بالأونصة أو بالغرام، مع لمس وسحب لمعرفة السعر في أي لحظة، وإحصاءات الافتتاح والأعلى والأدنى
- **الليرات الذهبية والسبائك**: الليرة السورية 8 غ، الرشادية، الإنكليزية، سبيكة 10 غ، الكيلو
- **أسعار الفضة** ونسبة الذهب إلى الفضة
- **حاسبة الذهب**: الوزن × العيار + المصنعية + ضريبة القيمة المضافة، وحساب "كم غرام أستطيع شراءه بمبلغ معين"
- **تنبيهات السعر**: إشعار عند تجاوز الأونصة حداً أعلى أو نزولها تحت حد أدنى (فحص كل 15 دقيقة في الخلفية)
- **مشاركة الأسعار** كنص عبر واتساب وغيره
- **العمل دون اتصال**: يعرض آخر سعر محفوظ
- **لوحة إعدادات**: سرعة التحديث، مصدر سعر الليرة (تلقائي أو يدوي بسعر السوق)، عرض الليرة الجديدة أو القديمة، الأعيرة المعروضة، هامش البيع المحلي، الكسور، الأرقام العربية/الإنجليزية، السمة الداكنة/الفاتحة، إبقاء الشاشة مضاءة، الضريبة، التنبيهات

## مصادر البيانات
| البيان | المصدر | ملاحظة |
|---|---|---|
| سعر الذهب والفضة الفوري | gold-api.com | احتياطي تلقائي: xaus.com ثم COMEX |
| المخطط البياني والتغير اليومي | عقود COMEX (GC=F) عبر Yahoo Finance | يُعاير على السعر الفوري |
| أسعار الصرف | ExchangeRate-API (open.er-api.com) | الريال مربوط رسمياً عند 3.75 |

> سعر الليرة السورية من المصادر العالمية قد يختلف عن سعر السوق المحلي. يمكنك اختيار **سعر يدوي** من الإعدادات وإدخال سعر الصرافة بالليرة الجديدة.

## طريقة البناء

### الطريقة 1: GitHub Actions (من الجوال)
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `GoldLive`).
2. ارفع **كل محتويات** هذا المجلد بما فيها المجلد المخفي `.github`.
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائياً (أو اضغط Run workflow).
4. بعد انتهاء البناء (حوالي 4–6 دقائق) حمّل **GoldLive-APK** من أسفل صفحة البناء، وفك الضغط وثبّت الملف.

### الطريقة 2: Android Studio
1. File ← Open ← اختر مجلد `GoldLive`.
2. انتظر انتهاء Gradle Sync.
3. Build ← Build App Bundle(s) / APK(s) ← Build APK(s).
4. الملف في: `app/build/outputs/apk/debug/app-debug.apk`

المتطلبات: JDK 17، Android SDK 34. الحد الأدنى للتشغيل: أندرويد 8.0.
